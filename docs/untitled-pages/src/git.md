Repositório
===========

```
git clone https://github.com/leozamboni/tiny-opt.git
```

URL: <https://github.com/leozamboni/tiny-opt>

Fluxo sugerido
--------------

1. Faça um fork no GitHub
2. Crie um branch para a alteração
3. Envie um pull request descrevendo o problema e a solução

Convenções
----------

- Código em C99, estilo GNU (`make format` usa `indent -gnu`)
- Módulos de otimização ficam em `opt/`
- Exemplos de regressão/demonstração em `examples/`
