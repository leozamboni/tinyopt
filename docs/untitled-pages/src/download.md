Código-fonte
============

O TinyOpt está disponível no GitHub:

<https://github.com/leozamboni/tiny-opt>

Clone
-----

```
git clone https://github.com/leozamboni/tiny-opt.git
cd tiny-opt
make
```

Dependências de build: `gcc`, `flex`, `bison` e `make`.

Releases
--------

Não há pacotes binários oficiais. Compile a partir do código-fonte.
