Template do site
================

Este website é escrito em Markdown e convertido para HTML estático com Pandoc
pelo gerador `untitled-pages`.

O template HTML original é de John MacFarlane (Pandoc); modificações
posteriores foram liberadas sob Creative Commons Zero 1.0.

Arquivos relevantes:

- [`template.include`](template.include) — template usado
- [`template.original`](template.original) — template original do Pandoc

O gerador `untitled-pages` é software livre (GPLv3). Ver `COPYING`.
